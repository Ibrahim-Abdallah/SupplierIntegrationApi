# Scalar screenshot capture guide

Capture these five PNG files manually from the real API's Development Scalar UI after code review. Do not use mockups, synthetic images, blank placeholders, or fabricated data.

| File | Required content |
|---|---|
| `scalar-overview.png` | Clean Scalar overview showing the API title and representative endpoint groups. |
| `scalar-manual-sync.png` | Manual supplier-sync operation with its summary and representative successful response. |
| `scalar-sync-history.png` | SyncRun history operation and a safe response showing status, trigger type, and counts. |
| `scalar-webhook.png` | Anonymous webhook operation showing documented signature/event headers and payload schema. |
| `scalar-products.png` | Products list operation and a representative synchronized Product response. |

Use a clean desktop viewport, a readable browser zoom, and only enough expanded content to tell each story. Prefer controlled demo data with clearly non-sensitive identifiers.

Before every capture, collapse, mask, redact, or move out of view all JWT values, passwords, supplier API keys, webhook secrets, full HMAC signatures, Authorization headers, connection strings, and personal/local information. Review the saved PNG at full resolution before adding it to Git.
